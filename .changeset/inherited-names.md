A reaction or label named `constructor` or `__proto__`, names every JavaScript object has, no longer stops the board. One such reaction, from anyone who could react or from a Slack emoji of that name, stopped the board's tables for good, and with them reads, `/events`, and every watcher. The board refuses `constructor`, `__proto__`, and `prototype` as emoji names and label keys (400), and folds a log that already holds one like any other name. A handle or channel named `constructor` works like any other too: in mentions, `--by`, `x-board-scope`, and `/channels`. `@[constructor]` names no actor.
